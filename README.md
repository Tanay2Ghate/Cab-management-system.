# Cab Management System

## Overview
The Cab Management System is a Java-based application designed to manage cab booking operations. It helps handle customers, drivers, vehicles, trips, payments, and ratings in an organized way. The system makes cab service management easier by storing and managing all important data efficiently.

## Features
- Add and manage customer details
- Add and manage driver details
- Manage vehicle information
- Book cab trips
- Track trip details
- Store payment information
- Add customer ratings and feedback
- View booking and driver records

## Technologies Used
- Java
- JDBC
- MySQL
- MySQL Workbench

## Modules
### Customer Module
Stores customer details such as name, phone number, and email.

### Driver Module
Stores driver details such as name, license number, phone number, and availability.

### Vehicle Module
Stores cab details such as vehicle number, model, type, and driver assigned.

### Trip Module
Handles cab booking details including pickup location, drop location, fare, and trip status.

### Payment Module
Stores payment details such as amount, payment mode, and payment status.

### Rating Module
Allows customers to rate drivers and provide feedback.

## Database Tables
- Customers
- Drivers
- Vehicles
- Trips
- Payments
- Ratings

## How to Run
1. Clone or download the project.
2. Open the project in any Java IDE like IntelliJ IDEA, Eclipse, or NetBeans.
3. Create a MySQL database.
4. Import or create the required database tables.
5. Update the database username, password, and database name in the Java connection file.
6. Run the main Java file.
